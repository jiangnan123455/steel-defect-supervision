# 两种检测模式

系统提供单张与批量两种检测模式，共用同一套推理、标注与统计逻辑，区别只在调度方式。
两种模式在页面右上区域（控制轨顶部）切换，**置信度阈值在两种模式间共用**。

---

## 模式一：单张检测

### 功能说明

一次上传一张产品表面图片，设置置信度阈值后启动检测。系统调用 YOLO 模型识别缺陷，
再通过 Supervision 绘制缺陷框、类别与置信度，并在页面上给出该图的区域分布与明细。

### 操作流程

1. 控制轨顶部选择「单张检测」。
2. 上传一张 JPG / JPEG / PNG 图片，或在「示例图片」里选一张样例。
3. 设置置信度阈值（0.05–0.95）。
4. 点击「开始检测」。
5. 系统调用 YOLO 识别缺陷，把输出转换为 Supervision 的 `Detections`。
6. 画布给出三种视图：标注结果 / 原图 / 九宫格。
7. 结果带依次给出指标条、九宫格区域分布、类别构成与置信度分级、缺陷明细。
8. 导出标注图 PNG 或明细 CSV。

### 页面展示

| 区域 | 内容 |
|---|---|
| 控制轨 | 模式切换、上传、阈值、执行、模型状态 |
| 画布 | 标注结果 / 原图 / 九宫格三视图切换 |
| 指标条 | 检出缺陷、涉及类别、平均置信度、单张耗时 |
| 区域与构成 | 九宫格计数与集中区域；类别构成、置信度分级 |
| 缺陷明细 | 类别、区域、置信度进度条、分级、框位置 |
| 导出 | 标注图 PNG、明细 CSV |

## 模式二：批量检测

### 功能说明

一次选择多张图片，系统**逐张**调用 YOLO 推理并标注，全部处理完成后汇总缺陷数量与
类别构成，并支持导出 CSV 检测报告。逐张推理，不代表多张图片并行处理。

### 操作流程

1. 控制轨顶部选择「批量检测」。
2. 一次选择多张 JPG / JPEG / PNG 图片；没有现成图片时，可打开
   「用六类样例组成一批」直接用 `samples/` 的六张样例演示。
3. 查看已选图片数量（画布上直接显示张数与缩略图）。
4. 设置本批次统一的置信度阈值。
5. 点击「开始批量检测」，进度条按「第几张 / 共几张」推进。
6. 系统逐张推理、标注，并在画布上给出每张的标注缩略图与缺陷数。
7. 查看批次概览、整批类别构成、异常与口径。
8. 在「批量明细」里逐条查看，下载 CSV。

### 页面展示

| 区域 | 内容 |
|---|---|
| 控制轨 | 多选上传、样例批、统一阈值、执行 |
| 画布 | 每张图片的标注缩略图 + 该图缺陷数（超过 6 张只预览前 6 张） |
| 批次概览 | 已选图片、已完成、累计缺陷、失败 |
| 整批类别构成 | 全批按类别合计，按数量降序 |
| 异常与口径 | 失败图片及原因；逐张推理与数量/体积上限说明 |
| 批量明细 | 图片名称、缺陷类型、置信度、检测状态；导出 CSV |

### 明细字段

| 字段 | 说明 |
|---|---|
| 图片名称 | 当前检测图片的文件名 |
| 缺陷类型 | 模型识别出的缺陷类别；未检出或失败时显示 `—` |
| 置信度 | 该缺陷的预测置信度，保留三位小数 |
| 检测状态 | `已完成` / `已完成 · 未检出` / `失败：<原因>` |

一行对应一个检出目标；未检出与失败的图片各占一行，保证明细条数与图片数可核对。

---

## 边界与约定

| 项 | 约定 |
|---|---|
| 单批数量 | 最多 20 张（`src/batch.py: MAX_BATCH_FILES`），超出部分不处理 |
| 单张体积 | ≤ 20 MB，与 `.streamlit/config.toml` 的 `maxUploadSize` 一致 |
| 失败处理 | 单张读取或推理失败只记录原因，继续处理其余图片，不中断整批 |
| 进度 | 逐张回调，页面显示「正在检测 n/共 N：文件名」 |
| 检出含义 | 「未检出」只表示当前阈值下没有检出目标，**不代表产品合格** |
| 缓存 | 批次结果按「文件名序列 + 阈值」缓存，改阈值或换图会重跑 |

实现见 `src/batch.py`（`run_batch` / `batch_rows` / `batch_csv`），
单元测试见 `tests/test_batch.py`。
