## 3. 训练配置

```bash
python train.py --model weights/yolov8n.pt --epochs 40 --imgsz 416 --batch 16 --device cpu --name steel_defect_yolov8n
```

| 参数 | 值 | 说明 |
|---|---|---|
| 起始权重 | yolov8n.pt（COCO 预训练） | 自动把检测头从 80 类改为 6 类 |
| 模型规模 | YOLOv8n（3.0M 参数，8.2 GFLOPs） | 轻量模型，CPU 可训练可推理 |
| 训练轮数 | 40 | |
| 输入尺寸 | 416×416 | 相比 640 显著缩短 CPU 训练时间 |
| 批次大小 | 16 | |
| 优化器 | AdamW（Ultralytics auto 选择，lr0=0.001） | |
| 随机种子 | 42 | |
| 设备 | CPU | |
| 数据增强 | mosaic=1.0, fliplr=0.5, hsv_h=0.015, hsv_s=0.7, hsv_v=0.4, scale=0.5, translate=0.1, close_mosaic=10 | Ultralytics 默认 |
| 预训练权重迁移 | 349/355 项成功迁移 | 检测头因类别数变化重新初始化 |

> 输入尺寸选择 416 而非 640，是在 CPU 训练时间与缺陷分辨率之间的折中。
> 钢材表面缺陷目标偏小，640 输入对小缺陷更有利，有 GPU 条件时建议重训。

### 区域分析人工核验

按方案书 8.3 节要求，区域分析指标以 **NEU-DET 测试集的人工标注为真值**
（`src/zone_eval.py`，逐图比对真值与模型预测的区域分布）。
以下为最终权重（40 轮）的实测结果：

| 指标 | 值 | 说明 |
|---|---:|---|
| 人工真值目标数 | 626 | NEU-DET 测试集标注 |
| 模型检出目标数 | 705 | 模型自身输出 |
| 区域计数总绝对误差 | 419 | 逐区域 \|真值−预测\| 之和 |
| 单图平均绝对误差 | 1.552 | 每张图平均差 1.55 个缺陷 |
| 热点区域命中数 | 152 / 270 | 真值与预测的集中区域一致 |
| 热点区域判断准确率 | 0.563 | |

**与中期（第 10 轮）对比**：区域总绝对误差 503 → 419（−16.7%），
单图平均误差 1.863 → 1.552，热点命中率 0.444 → 0.563（+26.8%）。

**结果解读（如实陈述）：**

1. 中期阶段误差主要来自漏检（当时 Recall 0.486）。最终模型 Recall 升至
   0.702，区域误差同步下降，验证了这一判断。
2. 最终模型检出数（705）**超过**真值数（626），说明误差来源已从漏检
   转向部分误检（Precision 0.659），单图平均误差仍有 1.55 个，
   距实用尚有差距。
3. 热点命中率 0.563 明显高于随机基线（九个区域随机命中约为 0.11），
   说明系统具备一定的区域分布判别能力。
4. 本指标体系只衡量"区域分布描述是否与人工判断一致"，
   **不代表产品质量等级，也不用于合格判定**。

复现：`python evaluate.py --weights weights/best.pt --conf 0.25 --imgsz 416`

### 中文字体兼容性

Supervision 的 `LabelAnnotator` 使用 `cv2.putText` 渲染文字，无法显示中文，
缺陷类别名会变成 "??"。本项目通过 `src/chinese_label.py` 的
`ChineseLabelAnnotator` 继承该标注器，只把文字渲染部分换成 PIL 的
TrueType 渲染，保持原有定位与配色逻辑。

- 字体查找顺序：微软雅黑 → 黑体 → 等线 → 文泉驿 → Noto CJK → 苹方
- 全部候选字体都不存在时自动降级为 ASCII 标签，程序不崩溃
- 12 个单元测试覆盖字体查找、中文渲染、输入图不被修改与降级路径

## 6. 已知问题与失败边界

- 仅用缺陷样本训练，未包含正常（无缺陷）样本，因此系统只输出"检出 / 未检出"，
  **不做合格判定**。
- 测试集整体 Recall 0.702，约三成真值缺陷未检出；416 输入下小缺陷偏小
  是主要原因之一。6 张演示样例（每类各一张）在最终模型下全部正确检出，
  包括中期权重曾漏检的 crazing_101，但更大的图片仍可能失败。
- 最终权重由验证集 mAP 挑选，偏向召回：测试集检出 705 个目标、超过真值
  626 个，Precision 0.659，存在部分误检。
- 单图 CPU 推理 94.4 ms（不含 UI），接近准实时，但不满足工业相机帧率要求。
- 上游 NEU-DET 数据集未声明许可协议，数据不随仓库分发。
