# 个人贡献说明

> 本文件记录本人在项目中的实际工作内容。答辩与简历中应只填写本人真实完成的部分。

## 一、数据整理

- 明确数据集选型：采用 NEU-DET 钢材表面缺陷数据集（六类缺陷，1797 张图片）。
- 核对上游数据集的图片来源、标注格式与许可状态，确认上游未声明许可协议，
  因此**不将数据集文件提交到 Git 仓库**，改为在 README 中说明获取方式。
- 选用清理修正版数据集（`KeenForgeAI/NEU-DET-corrected`），确认图片像素与
  官方版本一致，重复图片与重复标注框已修正，避免数据泄漏。
- 编写 `prepare_dataset.py`：按类别分层、固定随机种子（42）划分为
  训练 1257 / 验证 270 / 测试 270（70/15/15），自动生成 `data.yaml`。
- 编写 `prepare_samples.py`：从测试集中按类别各导出一张演示样例，
  保证样例图片来自测试集而非训练集。

## 二、模型训练与评估

- 编写 `train.py`：封装 Ultralytics 训练流程，固定关键参数与随机种子，
  训练结束后自动把 `best.pt` 复制到 `weights/` 目录。
- 在 CPU 环境下完成 yolov8n 的训练与验证，记录训练轮数、输入尺寸、批次等配置。
- 编写 `evaluate.py`：在独立测试集上计算 Precision、Recall、mAP@0.5、
  mAP@0.5:0.95，并统计九宫格区域分布与单图耗时，结果写入
  `outputs/reports/evaluation_report.json`。
- 记录真实的训练与评估指标，未做任何预先填写或估算。

## 三、Supervision 标注与区域分析

- 编写 `src/annotation.py`：使用 `sv.Detections.from_ultralytics()` 统一模型输出，
  用 `sv.BoxAnnotator` 与 `sv.LabelAnnotator` 绘制缺陷框、类别名与置信度。
- 编写 `src/zone_analysis.py`（项目核心创新点）：用 `sv.PolygonZone` 为九个区域
  分别构建多边形，以检测框中心点作为统一锚点统计区域归属。
- 定义并实现了边界归属规则：分割线上的目标按固定顺序唯一归属，
  保证九宫格计数之和等于参与统计的检测目标数。
- 补充区域类别构成统计与缺陷集中区域（hotspot）判定。

## 四、Web 页面与异常处理

- 编写 `app.py`：Streamlit 单页面，按方案书第 7 章完成六区布局
  （标题区、参数区、图片展示区、统计区、区域分析区、导出区）。
- 实现原图与标注图并排展示、九宫格分割线叠加、Plotly 区域热力柱状图、
  缺陷明细表格、标注图 PNG 与明细 CSV 下载。
- 完成异常处理：格式不支持、文件为空或过大、图片损坏、模型权重缺失、
  推理异常均有明确中文提示，页面不会崩溃退出。
- 明确"未检出缺陷 ≠ 产品合格"的表述，页面与提示中均使用"检出/未检出"，
  不做合格判定。

## 五、工程资料与测试
